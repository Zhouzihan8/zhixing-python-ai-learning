# S1-P01_文本统计工具

这是阶段课程配套项目，包含完整示例和可自行修改的动手版。

## 使用顺序

1. 先读本文件和 `项目入口.md`，了解目标、输入与结果。
2. 想先自己完成时，进入 `动手版/`，阅读 `开始项目.md`，按说明运行 `运行项目.py` 并用 `检查结果.py` 检查。
3. 卡住后再查看 `动手版/参考答案/`；完整示例留作对照。
4. 需要依赖时按 `动手版/开始项目.md` 建立虚拟环境，不要把本机 `.venv` 提交到仓库。

## 原项目说明

# S1-P01 文本统计工具

这是单独保存的参考实现。先在网站按 U05→U06→U07→U09→U10 完成自己的版本，再按需要查看这里。

在本目录运行 py -3 main.py。它读取 sample.txt，按次数降序、同次数按词升序输出，并生成 counts.json。

这里的三个关键词会得到：ai 2 次、python 2 次、model 1 次。输入空文件时输出零条记录、JSON 保存为空字典。

理解顺序：

1. textstats.py 里的 count_words 复用字典、循环和字符串。
2. sorted_counts 用键值对排序，不改变计数含义。
3. main.py 负责找文件、调用函数、显示和保存；__file__ 表示本脚本文件路径，parent 取得所在目录。
4. 入口保护使模块被导入时不会自动执行主流程。

自己增加一个变化：忽略 ai；随后把忽略词改为从调用参数传入。试着解释 None 默认值、列表浅拷贝和字符串不可变为什么不会在这里产生意外共享。

统计范围是按空白切分的简单词频，不宣称实现了中文分词或完整语言处理。
