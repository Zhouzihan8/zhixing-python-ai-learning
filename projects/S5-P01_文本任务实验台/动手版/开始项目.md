# S5-P01 文本任务实验台：动手版

完成 S5-U06 后组合本阶段知识；学到对应函数时即可分步完善。

复用 S3 的固定评价与 JSON 记录。先实现评价和失败记录，再接入实际模型；不让下载模型的问题挡住评价逻辑。

## 从这里开始

只编辑“我的项目.py”，入口、输入与检查代码已经接好；先看函数说明和 data/检查用例.json，明确输入输出。函数暂未实现时运行失败是正常的。

1. 先在固定历史响应上实现 evaluate_records；格式错误也要保留在总样本分母里。
2. 保存逐条结果和 failed_ids，区分格式失败和内容错误；这一步没有调用模型。
3. 准备模型环境后，复用 S5-U06 的 real_text_task.py 采集真实输出，转换为本项目 records 格式。
4. 固定相同输入比较两版提示；保留模型名称、生成配置和全部结果，不能覆盖失败记录。

## 运行与结果

在本目录终端执行：

~~~powershell
py -3 检查结果.py
py -3 运行项目.py
~~~

检查通过后，实际结果会写入 outputs/result.json。更换一份输入并解释结果；不能只让固定用例变绿。再回头看是否有把预期答案硬编码到函数中。

## 文件与求助顺序

- 我的项目.py：自己的实现，导出课程时保留。
- data/：小型输入和公开检查例子。
- 运行项目.py：负责读入、调用与保存，可打断点观察。
- 检查结果.py：检查函数的输入输出，不需要现在掌握检查器写法。
- 参考答案/：最后需要时再看；先定位失败用例、查本课提示。
