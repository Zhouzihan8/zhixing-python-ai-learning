# 知行 · Python 与 AI 学习书桌

一套从 Python 基础逐步走到深度学习、大模型、RAG 与 Agent 的中文学习站。课程按“先理解、先预测、动手修改，再带进项目”的顺序组织，适合学过 C/C++、但 Python 经验较少的学习者。

**在线学习站：** https://zhouzihan8.github.io/zhixing-python-ai-learning/

## 内容

- 6 个阶段、54 节课程，以及可点击跳转的知识树和知识关联图。
- 切片、对象引用、注意力权重等交互演示；每课都有可编辑代码、输入、输出、提示与参考思路。
- 54 个单课练习包和 6 个阶段项目包。项目目录同时提供完整示例、动手版、数据、检查脚本和使用说明。
- 项目覆盖文本统计、表格分析、分类实验、注意力、文本任务评价、文档问答。

## 开始学习

1. 打开在线学习站，从知识树的第一课开始，也可以点击任意知识点跳转。
2. 先阅读讲义并预测代码结果，再运行示例、改动一个输入或条件。
3. 需要在编辑器继续时，下载本课练习包，解压后在 VS Code 打开该文件夹；阶段项目也可从知识树下载。
4. 按项目说明安装该项目需要的依赖。不要把 `.venv`、个人作答、访问令牌或模型密钥提交到公开仓库。

## 浏览器代码运行范围

代码由 Pyodide 在浏览器 Web Worker 中运行。首次运行需要联网加载 Python 运行时和所需兼容包；CPU 与内存受浏览器限制。标准库和 Pyodide 可用的包适合小实验；PyTorch、GPU、完整 Transformers 推理、MySQL 服务等需要在本机环境中实践，课程提供下载包与运行说明。浏览器草稿保存在当前浏览器，不会同步到本机个人学习目录。

Pyodide 使用方式：[官方 Web Worker 指南](https://pyodide.org/en/stable/usage/webworker.html)、[官方标准输入输出指南](https://pyodide.org/en/stable/usage/streams.html)。

## 在本机预览

在 `site` 目录运行：

```powershell
py -3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000`。浏览器运行器首次启动仍需连接 Pyodide CDN。

## 目录

- `site/`：静态学习站、课程数据和练习下载包；GitHub Pages 从此目录发布。
- `projects/`：六个阶段项目源代码与逐步使用说明。
- `tests/`：公开内容、练习包与路径的发布检查。
- `.github/workflows/pages.yml`：推送到 `main` 后自动发布。

本仓库是公开静态版，不包含需要本机服务的个人学习站、个人进度或单课练习作答。本机版本仍保留独立的 Python 运行器和 VS Code 直达功能。
